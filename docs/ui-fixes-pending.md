## 1. 统计页「每日休息」柱子是灰色，读不出来

- **状态**：☐
- **现象**：记录页（周/月档）下方「每日休息」图表的柱子接近白色，和白底几乎分不开。
- **位置**：`ui/pages/RecordsPage.kt:202`
  ```kotlin
  HyperSection(title = "每日休息") {
      BarChart(data = restData, barColor = MiuixTheme.colorScheme.secondary, ...)
  }
  ```
- **根因（已确认）**：`MiuixTheme.colorScheme.secondary` 在 miuix 浅色板里是 `#E6E6E6`，
  本来就是给"浅灰底/次要按钮"用的，不是图表色。深色板里它更暗，同样没有对比。
- **可选做法**：
  - A. 换成 `onSurfaceVariantSummary`，再压到 35% 透明度 → 深灰柱，白/黑底都稳；
  - B. 用 `primary` 的同色相浅版（`primary.copy(alpha = 0.45f)`）→ 两张图同色系，靠深浅区分；
  - C. 给第二序列单独定一个固定色（如青绿/橙）。
- **倾向**：B。两张图并排看时"同色系不同深浅"比"两种颜色"更容易读成一类数据；
  若嫌区分度不够，再退到 A。
- **验收**：浅色、深色下各看一次周档与月档，柱子应清晰可辨、且与"每日亮屏"仍能区分。

## 2. 计时设置里的几项仍是滑块，想换成滚轮选择器

- **状态**：☐

  拖动调值，没有"一格一格"的手感。
- **位置**：`ui/pages/SettingsPage.kt` 的 `IntSliderRow`，共 4 处：
  | 设置项 | 范围 | 单位 | 行号 |
  |---|---|---|---|
  | 用眼提醒间隔 | 1–120 | 分钟 | ~176 |
  | 休息时长 | 5–300 | 秒 | ~184 |
  | 每日用眼目标 | 10–480 | 分钟 | ~194 |
  | 超时二次提醒 | 1–30 | 分钟 | ~217 |
- **可选做法**：
  - A. 行保持"标题 + 当前值 + 箭头"，点开 `OverlayBottomSheet` + `NumberPicker`（和现有免打扰时间选择同一套）；
  - B. 行内直接嵌 `NumberPicker`（一直可见）；
  - C. 只把跨度大的换滚轮，短跨度（超时提醒 1–30）保留滑块。
- **倾向**：A。与「免打扰 → 开始/结束时间」的交互一致，页面也不会被一排滚轮撑长；
  且现有 `TimePickerSheet` 已经验证过这套弹层能用。
- **注意**：落盘仍要"松手才写"——`updateSettings` 会重排闹钟，不能每滚一格就提交；

- **验收**：四个设置项都能点开滚轮、滚动跟手、确认后生效并回一条 Snackbar；取消不改值。
