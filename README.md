## 这是什么

「护眼时光」把 20-20-20 法则变成一条你不需要记的规则：

> 每连续用眼 20 分钟 → 向 20 英尺（约 6 米）外远眺 20 秒。

到点提醒、可选全屏休息页、休息结束轻响一声，然后进入下一个循环。没有账号，没有网络请求，没有广告位。

**你的数据只留在你自己的手机里。** 卸载即清除，作者也拿不到。

## 能做什么

| 页面 | 作用 |
|---|---|
| 计时 | 主界面。用眼 / 休息倒计时环，以及健康用眼知识。到点可以「开始休息」或「稍后再说」 |
| 报告 | 日 / 周 / 月的用眼与休息统计：柱状图、达标率 |
| 设置 | 提醒间隔、到点自动全屏、休息结束提示音、久坐提醒、免打扰时段、夜间模式，改完立即生效 |

### 一次提醒是怎么发生的

```text
用眼倒计时归零
      │
      ▼
  发出提醒（可选直接弹出全屏休息页）
      │
      ▼
   开始休息  ──→  休息结束：轻响一声，记录一次
      │                        │
      │                        ▼
      │                   回到用眼循环
      ▼
 到点一直不休息 → 继续计时，每隔几分钟再提醒一次
```

## 遇到问题怎么办

应用里有个 **设置 → 提醒可靠性自检**，会把「为什么提醒不准时」变成一份你自己能查的清单。下面是最常见的几种情况：

| 现象 | 怎么办 |
|---|---|
| 到点没有弹出全屏休息页 | 去 **设置 → 提醒可靠性自检** 看悬浮窗与全屏通知权限。手机息屏或锁屏时按设计不弹 |
| 到点完全没有提醒 | 检查通知权限、精确闹钟、电池优化——自检页会逐项告诉你在哪一项没过 |
| 锁屏或重启后不再提醒 | 部分手机的省电策略会禁止应用自启动：去 **手机设置 → 应用管理 → 护眼时光 → 允许自启动** |
| 免打扰时段没有生效 | 这是设计如此：免打扰只对久坐提醒生效，用眼与休息提醒不受影响 |
| 提示音没有声音 | 检查手机的通知音量（与微信、短信是同一档）。手机静音或勿扰模式下按设计不响 |
| 休息结束没有振动 | 振动跟随系统的「通知振动」设置，去手机设置里确认 |
| 统计数字偏少 | 统计读的是系统的屏幕记录，受系统数据保留期限制（通常数天到数周） |
| 「亮屏时长」比实际用眼时间长 | 这是设计如此：它统计的是屏幕亮着的时间，包含亮着但没在用的时段 |

## 关于隐私

- **不联网**：应用没有任何网络请求，也不需要网络权限。
- **不上报**：没有埋点、没有统计 SDK、没有崩溃上报。
- **不要多余权限**：不碰摄像头、通讯录、位置、无障碍。
- **数据只在本地**：设置与统计存在你自己的手机里，卸载即清除。

---

## 关于健康

本应用是一个**习惯提醒工具**，不是医疗设备，也不提供任何诊断或治疗建议。眼睛有不适请就医。
